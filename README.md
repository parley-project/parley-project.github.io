# parley-project.github.io

The website for [Parley](https://parley.bringardner.us), Java libraries for implementing internet protocols.

Everything is static: `index.html` plus the images in `assets/`, which come from
[parley-brand](https://github.com/parley-project/parley-brand). GitHub Pages serves the `master`
branch as is.

The site is published at https://parley.bringardner.us (the `CNAME` file sets the custom domain).
